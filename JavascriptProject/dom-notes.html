DOM Structure
Document Object Model — Structure & Manipulation
The DOM is a tree-structured, in-memory representation of an HTML page. Every tag becomes a node. JavaScript can traverse this tree and change any node — which instantly updates what the user sees.
🌳 What is the DOM?

When a browser loads an HTML page, it parses the markup and creates a tree of objects in memory. This tree is the DOM (Document Object Model).

The document object is the root. Every HTML element is a node. Text inside elements are text nodes. Attributes are attribute nodes.

dom-manipulation.js 
// ── 1. Select elements ──────────────────────────────────
const title  = document.getElementById('main-title');
const first  = document.querySelector('.card');       // first .card
const allBtn = document.querySelectorAll('button');   // NodeList

// ── 2. Read content ─────────────────────────────────────
console.log(title.textContent);       // plain text only
console.log(title.innerHTML);         // text + inner HTML tags
console.log(title.outerHTML);         // includes the element itself

// ── 3. Change content ───────────────────────────────────
title.textContent = 'New Title';       // safe — escapes HTML
title.innerHTML    = '<em>Italic</em>'; // parses HTML (XSS risk)

// ── 4. Change CSS styles ────────────────────────────────
title.style.color      = '#1c4ed8';
title.style.fontSize   = '24px';
title.style.display    = 'none';    // hide
title.style.display    = 'block';   // show

// ── 5. Add / Remove CSS classes (preferred) ─────────────
title.classList.add('active');
title.classList.remove('active');
title.classList.toggle('active');   // add if absent, remove if present
title.classList.contains('active'); // true/false

// ── 6. Read / write attributes ──────────────────────────
title.getAttribute('id');
title.setAttribute('data-role', 'header');
title.removeAttribute('hidden');
title.hasAttribute('disabled');      // true/false

// ── 7. Navigate the tree ────────────────────────────────
title.parentElement;          // the <body> or container above
title.children;               // HTMLCollection of child elements
title.firstElementChild;      // first child element
title.lastElementChild;       // last child element
title.nextElementSibling;     // next sibling element
title.previousElementSibling; // previous sibling
textContent vs innerHTML: Always use textContent when inserting user-supplied text. Using innerHTML with untrusted input can introduce Cross-Site Scripting (XSS) vulnerabilities because it parses and runs embedded scripts.

Events
Event Handling & Event Listeners
Events are signals fired by the browser when something happens — a click, a key press, a form submission. JavaScript listens for these signals with event listeners and runs a function in response.
📋 Three Ways to Handle Events

1. Inline (avoid) — mixes HTML and JS:

<button onclick="alert('Hi')">Click</button>

2. DOM property (one handler only):

btn.onclick = function() { alert('Hi'); };

3. addEventListener (recommended):

btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);
📋 Common Events Reference
CategoryEvents
Mouse click, dblclick, mousedown, mouseup, mouseover, mouseout, mousemove
Keyboardkeydown, keyup, keypress
Form submit, change, input, focus, blur, reset

events.js 
// ── addEventListener — the standard approach ─────────────
const btn = document.getElementById('my-button');

btn.addEventListener('click', function(event) {
  console.log('Clicked!', event.type);  // "click"
});

// ── The Event object ─────────────────────────────────────
btn.addEventListener('click', (e) => {
  console.log(e.type);          // event name: "click"
  console.log(e.target);        // element that was clicked
  console.log(e.currentTarget); // element the listener is on
  console.log(e.clientX, e.clientY); // mouse position
  e.preventDefault();           // stop default action (e.g. form submit)
  e.stopPropagation();           // stop event bubbling up the tree
});

// ── Keyboard events ──────────────────────────────────────
document.addEventListener('keydown', (e) => {
  console.log('Key:', e.key);       // 'Enter', 'a', 'Escape'…
  console.log('Code:', e.code);     // 'KeyA', 'Enter', 'Space'
  console.log('Ctrl?', e.ctrlKey); // true/false
  if (e.key === 'Enter') { submitForm(); }
});

// ── Event bubbling & delegation ──────────────────────────
// Events bubble UP the DOM tree: child → parent → document
// Event delegation = attach ONE listener to a parent
// instead of individual listeners on each child:
document.getElementById('list').addEventListener('click', (e) => {
  if (e.target.tagName === 'LI') {
    console.log('List item clicked:', e.target.textContent);
  }
});
Event Bubbling: When you click a child element, the event also fires on every ancestor up to the document. Use e.stopPropagation() to stop it. Event delegation takes advantage of bubbling — attach one listener to a parent element and handle all children inside that listener by checking e.target.

Creating & Modifying DOM Elements
JavaScript can build entirely new HTML elements, set their content and styles, and insert them anywhere in the document — all without touching the HTML file.
create-elements.js 
// ── Create a new element ─────────────────────────────────
const card = document.createElement('div');   // creates <div>

// ── Set its content, class, attributes ──────────────────
card.textContent     = 'Hello from JS!';
card.className       = 'card active';
card.id             = 'new-card';
card.setAttribute('data-role', 'info');

// ── Style it directly ────────────────────────────────────
card.style.background = '#eff6ff';
card.style.padding    = '16px';
card.style.borderRadius = '8px';

// ── Insert into the document ─────────────────────────────
const container = document.getElementById('container');
container.appendChild(card);      // add as last child
container.prepend(card);           // add as first child
container.insertBefore(card, ref); // before a reference node
ref.insertAdjacentElement('afterend', card); // after ref

// ── Remove an element ────────────────────────────────────
card.remove();                       // modern — remove self
container.removeChild(card);        // older approach

// ── Clone an element ─────────────────────────────────────
const clone = card.cloneNode(true); // true = deep clone (children too)
container.appendChild(clone);

// ── insertAdjacentHTML — insert HTML string efficiently ──
container.insertAdjacentHTML('beforeend', `
  <div class="card">
    <h3>Dynamic Card</h3>
    <p>Added without createElement</p>
  </div>
`);
// Positions: 'beforebegin' | 'afterbegin' | 'beforeend' | 'afterend'
📌 Insert Position Reference

📌 Modify Existing Elements
el.textContent = 'new text';
el.innerHTML = '<b>bold</b>';
el.style.color = 'red';
el.classList.add('active');
el.classList.remove('old');
el.classList.toggle('show');
el.setAttribute('href', '/new');
el.removeAttribute('disabled');

Performance tip: When adding many elements, build them into a DocumentFragment first, then insert the fragment once. This causes only one reflow instead of many. Example: const frag = document.createDocumentFragment(); → append children to frag → container.appendChild(frag);

Form Validation Using JavaScript
Form validation checks user input before it is sent to the server. JavaScript gives you full control — you can validate on each keystroke, on blur, or on submit, and show clear error messages next to each field.
📋 Accessing Form Values
// Get form element
const form = document.getElementById('reg-form');

// Read input values
const name  = document.getElementById('name').value;
const email = document.getElementById('email').value;
const sel   = document.getElementById('course').value;
const chk   = document.getElementById('terms').checked;

// Prevent submission until valid
form.addEventListener('submit', (e) => {
  e.preventDefault(); // stop page reload
  if (validate()) form.submit();
});

form-validation.js — complete pattern 
// Helper: show or hide an error message beside a field
function showError(fieldId, message) {
  const field = document.getElementById(fieldId);
  const errEl = document.getElementById(fieldId + '-error');
  field.classList.add('invalid');
  field.classList.remove('valid');
  errEl.textContent = message;
  errEl.style.display = 'block';
}

function showValid(fieldId) {
  const field = document.getElementById(fieldId);
  const errEl = document.getElementById(fieldId + '-error');
  field.classList.add('valid');
  field.classList.remove('invalid');
  errEl.style.display = 'none';
}

// Validate all fields — returns true if form is valid
function validateForm() {
  let isValid = true;
  const name  = document.getElementById('name').value.trim();
  const email = document.getElementById('email').value.trim();
  const pass  = document.getElementById('password').value;

  // Name: required, at least 3 characters
  if (!name) {
    showError('name', 'Name is required');
    isValid = false;
  } else if (name.length < 3) {
    showError('name', 'Name must be at least 3 characters');
    isValid = false;
  } else { showValid('name'); }

  // Email: required, valid format
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!email) {
    showError('email', 'Email is required');
    isValid = false;
  } else if (!emailRegex.test(email)) {
    showError('email', 'Enter a valid email address');
    isValid = false;
  } else { showValid('email'); }

  // Password: required, minimum 8 characters
  if (!pass) {
    showError('password', 'Password is required');
    isValid = false;
  } else if (pass.length < 8) {
    showError('password', 'Password must be at least 8 characters');
    isValid = false;
  } else { showValid('password'); }

  return isValid;
}
Real-time validation: Attach a listener to the input event (fires on every keystroke) or blur event (fires when focus leaves a field) to show errors as the user types — not just on submit. This gives much better user experience.
