01
Overview
Introduction to AngularJS
AngularJS (Angular 1) is an open-source JavaScript framework maintained by Google. Released in 2010, it brought server-side MVC architecture to the browser and introduced the concept of two-way data binding for single-page applications.
📋 What is AngularJS?
A JavaScript framework that extends HTML with new attributes. It follows the MVC pattern — Model (data), View (HTML), Controller (logic). The framework automatically keeps the View and Model in sync.
⚡ Key features
Two-way data binding · Directives (custom HTML) · Dependency injection · Routing (ngRoute) · Templates · Filters · Services · Form validation
🚀 How to start
Just add one <script> tag from CDN. No build tools, no npm, no Node.js needed. Then add ng-app to your HTML root element.
minimum AngularJS setup — 3 things needed
<!-- 1. Load AngularJS from CDN -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/angular.js/1.8.3/angular.min.js"></script>

<!-- 2. ng-app marks the Angular boundary -->
<html ng-app="myApp">

  <!-- 3. ng-controller connects JavaScript to HTML -->
  <div ng-controller="MyCtrl">
    <p>Hello, {{ name }}!</p>   <!-- displays $scope.name -->
  </div>

</html>

// JavaScript
var app = angular.module('myApp', []);

app.controller('MyCtrl', function($scope) {
  $scope.name = 'VTU Student';  // shows in HTML
});

02
Core Concept
Modules
A module is a container that holds all the parts of your AngularJS application — controllers, services, directives, and filters. Every AngularJS app has at least one module. Think of it as the main folder that organises everything.
What a module does
  • → Groups all related controllers, services, directives together
  • → Declares other modules it depends on (e.g. ngRoute)
  • → The name must match ng-app value in HTML
  • → Can be split into multiple files for large apps
Syntax — two forms
// CREATE a module (with empty [] dependencies)
var app = angular.module('myApp', []);

// With dependencies (ngRoute for routing)
var app = angular.module('myApp', ['ngRoute']);

// RETRIEVE an existing module (no [] array)
var app = angular.module('myApp');
// ↑ Used in separate .js files to add controllers
modules — complete example with dependency
<!-- HTML -->
<html ng-app="studentApp">  <!-- name MUST match module name -->

// app.js — create the module
var app = angular.module('studentApp', []);
//                          ↑ name     ↑ dependencies (empty = none)

// controller.js — add a controller to the SAME module
// Note: no [] here — we are RETRIEVING, not creating
angular.module('studentApp')
  .controller('HomeCtrl', function($scope) {
    $scope.title = 'Home Page';
  });

// service.js — add a service to the same module
angular.module('studentApp')
  .service('DataService', function() {
    this.getData = function() { return []; };
  });

03
Core Concept
Controllers
A controller is a JavaScript function that sets up the initial state and behaviour for a section of the HTML page. It is the C in MVC. It communicates with the View (HTML) through the $scope object.
What a controller does
  • → Puts initial data onto $scope (variables)
  • → Puts functions onto $scope (called from HTML)
  • → Responds to user events (clicks, form submits)
  • → Fetches data from services and passes to view
  • → Does NOT manipulate the DOM directly
Controller rules
  • ✓ One controller per section of the page
  • ✓ Controllers can be nested (child inherits parent scope)
  • ✓ Use services to share data between controllers
  • ✗ Do NOT use $scope to directly touch DOM elements
  • ✗ Do NOT put presentation logic in controllers
controllers.js — anatomy of a controller
var app = angular.module('myApp', []);

// Controller function takes $scope as argument
// $scope is injected by AngularJS automatically (Dependency Injection)
app.controller('StudentCtrl', function($scope) {

  // ── Data on $scope (available in HTML as variables) ──────
  $scope.studentName = 'Arjun';
  $scope.gpa          = 8.7;
  $scope.courses      = ['HTML', 'CSS', 'JavaScript'];

  // ── Functions on $scope (callable from HTML via ng-click etc) ──
  $scope.greet = function() {
    return 'Hello, ' + $scope.studentName + '!';
  };

  $scope.addCourse = function(course) {
    $scope.courses.push(course);     // DOM updates automatically
  };

  $scope.removeCourse = function(i) {
    $scope.courses.splice(i, 1);
  };
});

<!-- HTML uses the controller -->
<div ng-controller="StudentCtrl">
  <p>{{ studentName }} — GPA: {{ gpa }}</p>
  <p>{{ greet() }}</p>
  <li ng-repeat="c in courses">{{ c }}</li>
</div>

04
Core Concept
Scope — $scope & $rootScope
$scope is the glue between the controller and the view. It is a plain JavaScript object. Whatever you put on $scope in the controller is immediately accessible in the HTML template, and vice versa.
$scope — local to one controller
  • → Each controller gets its own $scope
  • → Variables on $scope are visible in that controller's HTML
  • → Nested controllers inherit parent's $scope
  • → Injected automatically — just add $scope as parameter
$rootScope — global, shared by all
  • → Accessible by ALL controllers across the app
  • → Parent of all other $scope objects
  • → Use sparingly — can cause tight coupling
  • → Inject as function($scope, $rootScope)
⚙ The Digest Cycle — how $scope updates work
When any event fires (click, input, HTTP response), AngularJS runs the digest cycle — it loops through all watchers, finds what changed, and updates the DOM. This is called dirty checking.

scope.js — $scope vs $rootScope
var app = angular.module('myApp', []);

// $rootScope — accessible everywhere in the app
app.controller('AppCtrl', function($scope, $rootScope) {
  $rootScope.appName = 'VTU Portal';  // visible to ALL controllers
  $scope.localData  = 'Only in AppCtrl';
});

// Child controller — inherits from parent scope
app.controller('ChildCtrl', function($scope, $rootScope) {
  // $rootScope.appName is accessible here too
  console.log($rootScope.appName);  // "VTU Portal"
});

<!-- HTML -->
<p>App: {{ appName }}</p>   <!-- $rootScope.appName -->
<p>{{ localData }}</p>     <!-- $scope.localData -->
$scope is NOT the same as a global variable. It is scoped to the ng-controller block it belongs to. Think of each controller as a room — $scope is visible only inside that room. $rootScope is visible in every room (the hallway).

Core Concept
Directives
Directives are special HTML attributes starting with ng- that give HTML new powers. They are AngularJS's way of extending HTML syntax. Every built-in Angular behaviour comes from a directive.
DirectivePurposeExample
ng-app Marks root of AngularJS application <html ng-app="myApp">
ng-controllerAttaches a controller to HTML section <div ng-controller="MyCtrl">
ng-model Two-way binds input to $scope variable <input ng-model="name">
ng-repeat Loops over array, repeats element <li ng-repeat="s in students">
ng-if Add/remove element from DOM <p ng-if="isLoggedIn">
ng-show Show/hide element (stays in DOM) <div ng-show="isActive">
ng-hide Opposite of ng-show <div ng-hide="isActive">
ng-click Calls a function on click <button ng-click="save()">
ng-submit Handles form submit, prevents reload <form ng-submit="login()">
ng-class Conditionally applies CSS classes ng-class="{'active':isOn}"
ng-style Dynamically sets inline CSS ng-style="{'color':col}"
ng-bind One-way bind, alternative to {{ }} <p ng-bind="name">
ng-include Includes external HTML template ng-include="'nav.html'"
ng-init Initialises scope variable inline ng-init="count=0"
ng-disabled Disables element based on condition ng-disabled="!isValid"

06
Core Concept
Expressions
Expressions are snippets of code written inside double curly braces {{ }} in the HTML. AngularJS evaluates them against the $scope and replaces them with the result. They are like a mini JavaScript engine in your HTML.
What expressions can contain
  • ✓ Variables from $scope: {{ name }}
  • ✓ Arithmetic: {{ 5 + 3 }} → 8
  • ✓ String concat: {{ 'Hello ' + name }}
  • ✓ Comparisons: {{ gpa > 7 }} → true/false
  • ✓ Ternary: {{ pass ? 'Pass' : 'Fail' }}
  • ✓ Function calls: {{ getGrade() }}
  • ✓ Object properties: {{ student.name }}
  • ✓ Array elements: {{ items[0] }}
What expressions CANNOT contain
  • ✗ No if statements (use ternary instead)
  • ✗ No for or while loops
  • ✗ No var, let, const declarations
  • ✗ No new keyword
  • ✗ No access to global objects like window or document
  • ✗ No throw exceptions
expressions.html — all expression types
<div ng-app="myApp" ng-controller="ExprCtrl">

  <!-- Variable from $scope -->
  <p>Name: {{ name }}</p>

  <!-- Arithmetic -->
  <p>Sum: {{ 10 + 20 }}</p>                    → 30
  <p>GPA * 10: {{ gpa * 10 }}</p>             → 87

  <!-- Ternary (if-else in one line) -->
  <p>Result: {{ gpa >= 7 ? 'Pass' : 'Fail' }}</p>  → Pass

  <!-- Object property -->
  <p>{{ student.name }} — {{ student.course }}</p>

  <!-- Array element -->
  <p>First course: {{ courses[0] }}</p>

  <!-- Function call -->
  <p>Grade: {{ getGrade(gpa) }}</p>

  <!-- With filter (pipe | ) -->
  <p>{{ name | uppercase }}</p>              → ARJUN
</div>

Core Concept
Filters
Filters format the value of an expression for display to the user. They are applied using the pipe | character inside {{ }} expressions or inside directives like ng-repeat.
Built-in filters
FilterWhat it does
uppercase Converts to UPPERCASE
lowercase Converts to lowercase
number:n Formats to n decimal places
currency:"₹"Formats as currency
date:'dd/MM/yy'Formats a date object
filter:termSearches array for matching items
orderBy:'field'Sorts array by a property
limitTo:n Takes first n items from array
json Formats object as JSON string
Filter syntax reference
<!-- In expressions -->
{{ name | uppercase }}
{{ gpa | number:2 }}
{{ fee | currency:"₹" }}
{{ today | date:'dd MMM yyyy' }}

<!-- Chaining filters -->
{{ name | uppercase | limitTo:5 }}

<!-- In ng-repeat -->
<tr ng-repeat="s in students
  | filter:searchText
  | orderBy:'name'
  | limitTo:10">

// Custom filter in JavaScript
app.filter('grade', function() {
  return function(gpa) {
    return gpa >= 9 ? 'A+'
         : gpa >= 8 ? 'A'
         : gpa >= 7 ? 'B'
         : 'C';
  };
});

Exam Prep
VTU Quick Reference
ng-appBootstraps AngularJS on a page. Value must match the module name in angular.module().
angular.module(name,[])Creates the Angular module. [] = dependency array. No [] = retrieves existing module.
app.controller(name,fn)Creates a controller. fn receives $scope via Dependency Injection automatically.
$scopeThe bridge between controller and view. Variables and functions on $scope are accessible in HTML.
$rootScopeGlobal scope — accessible by ALL controllers. Use sparingly to avoid tight coupling.
ng-modelTwo-way binding on inputs. User types → $scope updates. $scope updates → input updates.
ng-repeatLoops over an array. Creates one element per item. Use $index for position number.
ng-if vs ng-showng-if adds/removes from DOM. ng-show keeps in DOM but toggles visibility (display:none).
{{ expression }}Displays $scope value. Supports arithmetic, ternary, function calls, object properties.
| filterPipe character applies a filter. Formats value for display. Can be chained: | uppercase | limitTo:5
Digest cycleAngularJS change detection — loops all watchers after events, updates DOM for changed values. Called dirty checking.
Dependency InjectionAngularJS reads parameter names and injects matching services. Add $http to get HTTP service automatically.
