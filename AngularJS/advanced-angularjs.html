Services & Dependency Injection
A service is a reusable singleton object that holds shared logic or data. Instead of duplicating code across controllers, you put it in a service and inject it wherever needed. AngularJS handles the injection automatically — this is called Dependency Injection (DI).
Why services exist

Without services, you would copy-paste the same array or function into every controller that needs it. If the data changes, you update it in ten places instead of one.

A service solves this — it is created once (singleton) and shared across all controllers. It is the Model layer in AngularJS MVC.

Three ways to create services
MethodUse when
.service()Class with methods — this.method = fn
.factory()Returns an object or function — more flexible
.provider()Configurable before app starts — advanced
services.js — service vs factory + $http
// ── Method 1: .service() — uses 'this' ──────────────────
app.service('StudentService', function() {

  // Private data — only accessible via the methods below
  var students = [
    { name: 'Arjun', gpa: 8.7, course: 'MCA' },
    { name: 'Priya', gpa: 9.1, course: 'MCA' },
  ];

  // Public methods attached to 'this'
  this.getAll = function() { return students; };

  this.add = function(s) { students.push(s); };

  this.remove = function(i) { students.splice(i, 1); };

  this.getAvgGPA = function() {
    var sum = students.reduce(function(a,s){ return a+s.gpa; }, 0);
    return (sum / students.length).toFixed(1);
  };
});

// ── Method 2: .factory() — returns an object ─────────────
app.factory('MathFactory', function() {
  return {
    grade: function(gpa) {
      return gpa >= 9 ? 'A+' : gpa >= 8 ? 'A' : gpa >= 7 ? 'B' : 'C';
    },
    percentage: function(gpa) { return ((gpa / 10) * 100).toFixed(0) + '%'; }
  };
});

// ── Built-in $http service — AJAX calls ──────────────────
app.controller('DataCtrl', function($scope, $http) {
  $http.get('https://jsonplaceholder.typicode.com/users')
    .then(function(response) {
      $scope.users = response.data;   // data auto-updates the view
    })
    .catch(function(err) {
      $scope.error = 'Failed to load data';
    });
});

// ── Inject custom service into controller ────────────────
// AngularJS reads parameter NAMES and injects matching services
app.controller('HomeCtrl', function($scope, StudentService, MathFactory) {
  $scope.students = StudentService.getAll();
  $scope.avgGPA   = StudentService.getAvgGPA();

  $scope.getGrade = function(gpa) {
    return MathFactory.grade(gpa);
  };
});

Dependency Injection in one sentence: AngularJS reads the name of each parameter in your controller function and automatically finds and passes in the matching service. That is why function($scope, StudentService) works — AngularJS injects $scope and your custom StudentService automatically.

Routing & Single Page Applications
AngularJS routing (via ngRoute) lets you build a Single Page Application — the URL changes, different views appear, but the browser never reloads the page. Each URL maps to a controller and an HTML template.
How routing works
  1. 1. User clicks a link
  2. 2. URL changes to #!/home (hash-based)
  3. 3. $routeProvider matches the path
  4. 4. Loads the matched controller + template
  5. 5. <div ng-view> is replaced with the template
  6. 6. No page reload — just DOM swap
Setup requirements
<!-- 1. Load ngRoute (separate script) -->
<script src="angular-route.min.js"></script>

// 2. Declare dependency on ngRoute
var app = angular.module('myApp', ['ngRoute']);
//                                  ↑ required

<!-- 3. Outlet in HTML -->
<div ng-view></div>
<!-- ↑ views swap here -->
routing.js — complete $routeProvider config
var app = angular.module('studentApp', ['ngRoute']);

// ── Configure routes using app.config() ──────────────────
// app.config runs BEFORE controllers — used for route setup
app.config(function($routeProvider) {

  $routeProvider

    .when('/home', {
      templateUrl: 'views/home.html',
      controller:  'HomeCtrl'
    })

    .when('/students', {
      templateUrl: 'views/students.html',
      controller:  'StudentCtrl'
    })

    .when('/students/:id', {
      // :id is a route parameter — accessible via $routeParams
      templateUrl: 'views/detail.html',
      controller:  'DetailCtrl'
    })

    .otherwise({ redirectTo: '/home' });  // catch-all
});

// ── Read route params in a controller ────────────────────
app.controller('DetailCtrl', function($scope, $routeParams, StudentService) {
  var id = $routeParams.id;    // reads :id from URL
  $scope.student = StudentService.getById(id);
});

<!-- Navigate using href="#/students" or ng-href ──────── -->
<a href="#!/home">Home</a>
<a ng-href="#!/students/{{ student.id }}">View</a>

Each view is a separate HTML template loaded into <div ng-view>. The Angular Router swaps the template and runs the matching controller — no page reload.

ng-view is the key: Put one <div ng-view></div> anywhere in your page. AngularJS replaces its contents with the matching template every time the URL changes. Everything outside ng-view (navbar, footer) stays unchanged.

Data Binding & Form Handling
AngularJS provides rich two-way data binding via ng-model and a complete form validation system. Every input field can be validated in real time — without writing any event listeners.
One-way vs Two-way binding
TypeSyntaxDirection
Interpolation{{ name }}Scope → View only
ng-bind ng-bind="name"Scope → View only
ng-model ng-model="name"Scope ↔ View (both ways)
Form validation states
StateWhat it means
$valid All validations pass
$invalid At least one validation fails
$pristine User has not touched the field
$dirty User has interacted with the field
$touched Field has been focused and blurred
forms.html — complete form with validation
<!-- name="regForm" — gives us $scope.regForm object for validation -->
<form name="regForm" ng-submit="submit()" novalidate>

  <!-- required — field cannot be empty -->
  <input ng-model="student.name"
         name="name"
         required
         minlength="3">

  <!-- Show error ONLY when dirty (user touched) AND invalid -->
  <p ng-show="regForm.name.$dirty && regForm.name.$invalid">
    <span ng-show="regForm.name.$error.required">Name is required</span>
    <span ng-show="regForm.name.$error.minlength">Min 3 characters</span>
  </p>

  <!-- email type — validates email format automatically -->
  <input ng-model="student.email"
         name="email"
         type="email"
         required>

  <!-- ng-disabled — prevent submit until form is valid -->
  <button type="submit"
          ng-disabled="regForm.$invalid">
    Register
  </button>

</form>

// Controller reads $scope.student (bound by ng-model)
$scope.submit = function() {
  if ($scope.regForm.$valid) {
    StudentService.add($scope.student);
    $scope.student = {};           // clear form
    $scope.regForm.$setPristine();  // reset validation state
  }
};

Custom Directives & Components
You can create your own HTML tags and attributes that encapsulate behaviour. A custom directive is AngularJS's reusable component system — define it once, use it anywhere as a custom HTML element.
Directive types
restrictUsageExample
'E'Element (custom tag)<student-card>
'A'Attribute<div student-card>
'C'Class nameclass="student-card"
'EA'Element or AttributeBoth work
Directive lifecycle hooks
HookWhen it runs
link After directive is in DOM — most common
compile Before DOM insertion — for template changes
controllerCreates an inner controller for the directive
custom-directives.js — three patterns
// ── Pattern 1: Simple element directive ──────────────────
app.directive('loading', function() {
  return {
    restrict:  'E',                            // <loading>
    template:  '<div class="spinner">Loading…</div>'
  };
});
<!-- Usage: <loading></loading> -->

// ── Pattern 2: Directive with isolated scope + props ─────
app.directive('studentCard', function() {
  return {
    restrict:  'E',
    scope: {
      name:   '@',     // @ = read string attribute
      gpa:    '=',     // = = two-way bind to parent scope variable
      onView: '&'      // & = call a function from parent scope
    },
    template: `
      <div class="card">
        <h3>{{ name }}</h3>
        <p>GPA: {{ gpa }}</p>
        <button ng-click="onView()">View Details</button>
      </div>`,
  };
});
<!-- Usage: <student-card name="Arjun" gpa="student.gpa"
            on-view="viewStudent()"></student-card> -->

// ── Pattern 3: link function — accesses DOM directly ─────
app.directive('highlight', function() {
  return {
    restrict: 'A',              // attribute: <p highlight>
    link: function(scope, element, attrs) {
      // 'element' is the DOM element wrapped in jqLite
      var color = attrs.highlight || 'yellow';
      element.css('background', color);

      element.on('mouseenter', function() {
        element.css('opacity', '0.7');
      });
      element.on('mouseleave', function() {
        element.css('opacity', '1');
      });
    }
  };
});

service.js
Create the StudentService
Put all data and business logic in a service so all controllers share the same array. If HomeCtrl and ListCtrl both inject StudentService, they both see the same data.
Step 3 — service.js
app.service('StudentService', function() {

  var students = [
    { id:1, name:'Arjun', roll:'4MCA001', gpa:8.7, course:'MCA' },
    { id:2, name:'Priya', roll:'4MCA002', gpa:9.1, course:'MCA' },
  ];
  var nextId = 3;

  this.getAll     = function()    { return students; };
  this.getById    = function(id)  { return students.find(function(s){ return s.id == id; }); };
  this.add        = function(s)   { s.id = nextId++; students.push(s); };
  this.remove     = function(id)  { var i = students.findIndex(function(s){ return s.id==id; }); students.splice(i,1); };
  this.getAvgGPA  = function()    {
    var sum = students.reduce(function(a,s){ return a+s.gpa; },0);
    return (sum/students.length).toFixed(1);
  };
});

Your Tasks — Implement These
Six tasks of increasing difficulty. Complete them by modifying the project you built in §5. Each task targets one advanced concept.
★ Easy — Services
Add a CourseService
Create a new service called CourseService that holds a list of available courses. Inject it into the AddCtrl and use it to populate the course <select> dropdown with ng-options instead of hardcoded options.
★ Easy — Routing
Add an About route
Add a new route /about that shows a static information page about the portal. Add a nav link. The page should display the total number of students using StudentService.getAll().length.
★★ Medium — Forms
Add Edit functionality
Create an /edit/:id route and EditCtrl. Pre-populate the form fields with the existing student data from StudentService. On submit, update the record (not add a new one). Add an "Edit" button in the student detail view.
★★ Medium — Directives
Build a gpa-bar directive
Create an element directive <gpa-bar gpa="8.7"> that renders a horizontal progress bar. The bar width should be gpa * 10%. Bar colour should change — green for ≥8, blue for ≥7, amber for below 7. Use the link function.
★★★ Hard — $http Service
Load students from an API
Replace the hardcoded array in StudentService with a call to https://jsonplaceholder.typicode.com/users using $http.get(). Map the API response fields to match your student object shape. Show a loading state while fetching.
★★★ Hard — Full Feature
Add Search + Sort + Pagination
In the student list view: (1) add a search input using filter:searchText, (2) add Sort by Name/GPA buttons using orderBy, (3) add simple pagination — show 5 students per page using limitTo and track the current page in $scope.
How to get started: Take the project built in §5 (the single HTML file). Open it in VS Code or any text editor. Add the scripts at the bottom, save, and refresh in Chrome. Use Chrome DevTools Console to see errors — AngularJS error messages are detailed. Start with Task 01 and work up.

Advanced AngularJS — Quick Reference
app.service(name, fn)Creates singleton service. Methods defined on this. Shared across all controllers.
app.factory(name, fn)Creates service by returning an object. More flexible than .service().
Dependency InjectionAngular reads parameter names and injects matching services automatically. Add service name as parameter to controller function.
$routeProvider.when()Maps a URL path to a templateUrl and controller. Configured inside app.config().
ng-viewThe outlet where router swaps templates. Place once in the main HTML. Everything outside stays.
$routeParamsInject to read URL parameters. Route /:id → $routeParams.id gives the value.
$location.path()Programmatic navigation. $location.path('/students') navigates without an anchor tag.
regForm.$validForm object created when name="regForm" on the form element. $valid, $invalid, $dirty, $pristine.
app.directive(name, fn)Creates custom HTML element/attribute. Returns object with restrict, scope, template, link.
scope: { x: '@' }@ = read string. = = two-way bind. & = call expression. Creates isolated scope.
link: fn(scope,el,attrs)Runs after directive is in DOM. Use to access and manipulate the DOM element directly.
$http.get(url).then()Built-in AJAX service. Returns promise. response.data holds parsed JSON from server.
